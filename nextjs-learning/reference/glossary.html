Next.js terms (App Router)

Use these words consistently in lessons and in interview answers. Definitions track official docs language.

App Router
File-system router under app/. Folders define URL segments; special files define UI and behavior. Docs
Server Component
Default in App Router. Renders on the server; can async-fetch data and keep secrets off the client; no browser hooks/events. React
Client Component
Marked with "use client". Needed for state, effects, event handlers, and browser APIs. Ships JS to the browser. Docs
RSC Payload
Compact representation of the rendered Server Component tree sent to the client so React can reconcile UI without shipping all server logic as JS.
Hydration
Attaching event handlers to server-rendered HTML so Client Components become interactive.
Server Action / Server Function
Server-side function you can call from forms/components to mutate data, often with cache revalidation afterward. Docs
Route Handler
route.ts endpoint for HTTP methods — closer to Express routes when you need a real API/webhook surface.
Layout
Shared UI that wraps pages and persists across navigations (layout.tsx).
Proxy
Request interception layer (historically middleware; newer docs use Proxy) for auth redirects, headers, etc. Confirm the filename for your Next.js version in current docs.
Revalidation
Updating cached data/UI on a timer or on demand after a mutation.
