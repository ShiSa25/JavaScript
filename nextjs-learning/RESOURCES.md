# Next.js Resources

## Knowledge

- [Course: Next.js App Router (Dashboard) — nextjs.org/learn](https://nextjs.org/learn/dashboard-app)
  Official free course: builds a full-stack dashboard covering routing, data, streaming, mutations, auth, metadata. Use for: primary structured curriculum after Server/Client mental model.
- [Docs: Getting Started (App Router)](https://nextjs.org/docs/app/getting-started)
  Canonical topic order for core features (layouts, navigation, Server/Client Components, fetching, mutations, caching, errors, deploy). Use for: checklist while building projects.
- [Docs: Server and Client Components](https://nextjs.org/docs/app/getting-started/server-and-client-components)
  Official rules for when to use each, composition patterns, `server-only`. Use for: the MERN → Next.js mental shift and interview “why not use client everywhere?” answers.
- [React: Server Components reference](https://react.dev/reference/rsc/server-components)
  Primary React docs on RSC. Use for: grounding claims about what runs on server vs client.
- [Course: React Foundations — nextjs.org/learn](https://nextjs.org/learn/react-foundations)
  Official React primer ending in “From React to Next.js.” Use for: refresh only if a React gap shows up; skip most chapters given MERN comfort — jump to From React to Next.js if needed.
- [Auth.js — Getting Started / Next.js](https://authjs.dev/getting-started/installation)
  Official auth library used in Next.js ecosystem examples (formerly NextAuth). Use for: auth-gated portfolio apps and interview auth architecture questions.

## Wisdom (Communities)

- [Next.js Discord](https://nextjs.org/discord)
  Official community linked from Learn courses. Use for: stuck-on-docs questions, pattern sanity checks.
- [r/nextjs](https://www.reddit.com/r/nextjs)
  Active practitioner discussion; signal varies — prefer answers that cite docs. Use for: “how do people structure X in production?” after you’ve tried the docs approach.
- [Next.js GitHub Discussions](https://github.com/vercel/next.js/discussions)
  Closer to maintainers and detailed bug/API threads. Use for: framework-behavior edge cases.

## Gaps

- No single gold-standard “Next.js interview question bank” from Vercel; interview prep will be built from docs concepts + explaining your own projects.
- Auth.js docs note the project is evolving (Better Auth relationship) — verify current recommended package when implementing auth lessons.
