# Mission: Next.js for job readiness

## Why
Become hireable as a Next.js / full-stack React engineer by shipping a portfolio of real App Router projects and being able to explain those choices in interviews — not just “know MERN with a different folder structure.”

## Success looks like
- Ship 4–5 distinct Next.js apps that cover marketing, content, dashboard/CRUD, and auth-gated product patterns
- Explain App Router concepts in interviews: Server vs Client Components, rendering, caching/revalidation, Server Actions, routing conventions
- Map MERN instincts (SPA + Express API) to Next.js equivalents without defaulting to “everything is a Client Component + Route Handler”
- Complete mock interview explanations for at least one shipped project end-to-end

## Constraints
- ~4 hours per day available for learning and building
- Already comfortable with MERN (React SPA patterns, Express, Mongo)
- Prefer App Router / current Next.js — not legacy Pages Router unless needed for an old codebase question

## Out of scope
- Deep Pages Router mastery
- Native mobile (React Native)
- Heavy DevOps / Kubernetes
- Becoming a TypeScript language expert before shipping (use TS pragmatically; deepen later)
